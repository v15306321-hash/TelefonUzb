# TELEFON.UZB premium — сайт магазина смартфонов

Премиальная цифровая витрина физического магазина: полноэкранное видео-hero с «стеклянным» поиском,
каталог с фильтрами, страницы товаров с галереей фото по цветам, контакты, RU/UZ-локализация и
защищённая админ-панель. Публичный сайт и админка работают с одной базой PostgreSQL.

## Стек

| Слой | Технологии |
|---|---|
| Фреймворк | Next.js 15 (App Router, Server Components, Server Actions), React 19, TypeScript |
| Стили | Tailwind CSS 4, шрифт Inter (self-hosted, кириллица) |
| Данные | PostgreSQL + Prisma ORM, валидация zod на сервере |
| Авторизация | bcrypt-хеши паролей, подписанные JWT-сессии в httpOnly cookie (jose), rate-limit входа |
| Файлы | PostgreSQL (по умолчанию) или любое S3-совместимое хранилище |

## Быстрый старт (локально)

```bash
cp .env.example .env          # заполните DATABASE_URL, AUTH_SECRET, ADMIN_USERNAME, ADMIN_PASSWORD
npm install
npx prisma migrate deploy     # создать таблицы
npm run db:seed               # админ, категории, бренды, демо-каталог, настройки
npm run dev                   # http://localhost:3000  ·  админка: /admin
```

## Структура

```
src/
  app/
    [locale]/            публичный сайт: /ru/…, /uz/… (главная, каталог, товар, контакты, 404)
    admin/               админ-панель (вход, обзор, товары, категории/бренды, контент, аккаунт)
    api/media/[id]       раздача загруженных файлов (Range-запросы для видео, immutable-кэш)
    api/search           поиск для подсказок в hero
    api/admin/upload     загрузка файлов (проверка сессии, Origin, типа по сигнатуре, размера)
    api/admin/backup     JSON-экспорт каталога
  components/
    site/                Header, HeroVideo, SearchBox, ProductCard, CatalogFilters, ProductShowcase, ProductGallery…
    admin/               UI-кит админки, ProductForm, ContentForm, TaxonomyManager
  i18n/                  конфиг языков и словари ru.ts / uz.ts (типизированы — пропуск ключа = ошибка сборки)
  lib/                   catalog (запросы + кэш), search (транслитерация «айфон» → iphone), storage, auth, settings
```

## Фото товаров и галерея

* Каждое фото товара можно привязать к цвету (или «для всех цветов»). На странице товара при выборе
  цвета показываются только его фото: спереди/сзади, сзади + сбоку, крупный план камеры и т.д.
* Галерея: свайп на телефоне, стрелки и миниатюры на компьютере, полноэкранный просмотр по нажатию.
* Первое фото товара — обложка в каталоге (белая студийная панель).
* Демо-фото лежат в `prisma/seed-assets/photos` (1600×1600 и 1600×2000, WebP). Seed добавляет недостающие
  фото и привязывает их к цветам, но никогда не возвращает фото, удалённые в админке.

## Мультиязычность

* URL с префиксом языка: `/ru/…`, `/uz/…`; корень `/` перенаправляет на сохранённый язык (по умолчанию RU).
* Выбор сохраняется в cookie (для сервера) и localStorage (резерв), восстанавливается при повторном визите.
* Переключатель сохраняет текущую страницу и параметры фильтров.
* `hreflang`, canonical, локализованные title/description, `sitemap.xml` со всеми языковыми версиями.
* Тексты товаров/категорий/контента имеют отдельные RU/UZ-поля; пустой UZ → показывается RU.
* Новый язык: добавить код в `src/i18n/config.ts`, словарь в `src/i18n/dictionaries/`.

## Админ-панель (`/admin`)

* Вход по логину и паролю, bcrypt (12 раундов), JWT-сессия 12 ч в httpOnly/SameSite cookie, rate-limit
  попыток входа, защита маршрутов в middleware и повторная проверка в каждом server action / API.
* «Завершить все сессии» и смена пароля инвалидируют старые токены (tokenVersion).
* Обзор: всего / в наличии / нет в наличии / категорий, последние добавленные товары, журнал изменений.
* Товары: CRUD, поиск, фильтры по категории/бренду/наличию/видимости, сортировка по цене и дате,
  быстрое переключение наличия и видимости, удаление с подтверждением вводом адреса товара.
* Категории и бренды: создание, редактирование, скрытие, удаление (запрещено, если есть товары).
* Контент: логотип, фоновое видео (десктоп/мобайл), обложка-fallback, тексты главной, контакты,
  ссылка на локацию, адрес, часы работы, рекламные баннеры. Всё применяется без повторного деплоя.

Создать/сбросить администратора: `ADMIN_USERNAME=owner ADMIN_PASSWORD='…' npm run admin:create`.

## Хранение файлов и резервные копии

* `STORAGE_DRIVER=db` (по умолчанию) — файлы хранятся в PostgreSQL и попадают в обычные бэкапы БД.
* `STORAGE_DRIVER=s3` + `S3_*` — AWS S3, Cloudflare R2, MinIO и т.п. URL файлов (`/api/media/<id>`) не меняются.
* Изображения при загрузке нормализуются (EXIF-поворот, ≤2000 px, WebP); тип файла проверяется по сигнатуре.
* `npm run db:backup` — полный дамп `pg_dump` в `backups/` (хранятся 14 последних).
  Восстановление: `pg_restore --clean --if-exists -d "$DATABASE_URL" backups/<файл>.dump`.
* В админке («Аккаунт и данные») — быстрый JSON-экспорт каталога и настроек.

## Деплой (Render)

`render.yaml` описывает веб-сервис и PostgreSQL. При старте выполняются миграции и идемпотентный seed.
Обязательно задайте `ADMIN_PASSWORD` и `NEXT_PUBLIC_SITE_URL`. Подойдёт и любой Node-хостинг:
`npm ci && npm run build`, затем `npx prisma migrate deploy && npm run db:seed && npm start`.

## Примечание о демо-данных

Каталог заполнен демонстрационными товарами (цены в сумах, характеристики ориентировочные) —
перед запуском проверьте и обновите их в админке.
